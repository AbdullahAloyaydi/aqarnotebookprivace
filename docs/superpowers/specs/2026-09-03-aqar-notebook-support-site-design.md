# تصميم موقع الدعم والخصوصية لتطبيق دفتر العقار

## الهدف

إنشاء موقع عربي عام وخفيف يصلح مباشرة لحقلَي **Support URL** و**Privacy Policy URL** في App Store Connect، ويمنح مستخدم تطبيق **دفتر العقار** إجابة واضحة وسريعة من الهاتف دون تسجيل دخول.

## النطاق

- صفحة رئيسية للدعم في `index.html`.
- صفحة مستقلة لسياسة الخصوصية في `privacy.html`.
- ملف أنماط مشترك في `styles.css`، بلا JavaScript أو تحليلات أو ملفات من شبكات خارجية.
- نشر الملفات من جذر فرع `main` بواسطة GitHub Pages.

لا يشمل الموقع نماذج تواصل، حسابات، قاعدة بيانات، ملفات تعريف ارتباط، تحليلات، أو تتبع.

## الهوية وتجربة الاستخدام

- واجهة عربية بالكامل واتجاه RTL، مع ملخص إنجليزي قصير في سياسة الخصوصية لمراجعة المتجر.
- مظهر حديث وهادئ مستمد من هوية التطبيق: خلفية فاتحة دافئة، لون أخضر داكن، بطاقات بسيطة، وحواف واضحة.
- تخطيط عمود واحد بعرض قراءة مريح، مع أهداف لمس كبيرة وتباين قوي ودعم شاشات الهاتف والنص المكبّر.
- استخدام أيقونة التطبيق المحلية بعد نسخها من مستودع التطبيق؛ لا خطوط أو مكتبات أو صور خارجية.

## صفحة الدعم

تحتوي الصفحة على:

1. اسم التطبيق ووعده المختصر: تسجيل العقارات وحفظها والرجوع إليها ومشاركة نسخة منظمة.
2. توضيح أن التطبيق عربي، محلي أولًا، ويعمل دون حساب.
3. خطوات مختصرة للاستخدام: إضافة عقار، العثور عليه، فتح الموقع، إنشاء PDF أو مشاركته، والنسخ الاحتياطي.
4. أسئلة شائعة عن الحفظ التلقائي، الصور، الموقع، فقد الجهاز، والاستعادة.
5. زر بريد مباشر إلى `abdullah.aloyaydi.cs@gmail.com` بعنوان دعم تطبيق دفتر العقار.
6. رابط واضح إلى سياسة الخصوصية.

## سياسة الخصوصية

تصف السياسة السلوك الفعلي لتطبيق V1 فقط:

- لا حسابات، إعلانات، تحليلات، تتبع، أو خادم للمطور.
- بيانات العقارات وجهات الاتصال والملاحظات والإعدادات تحفظ محليًا على جهاز المستخدم.
- الصور المنسوخة إلى مساحة التطبيق تبقى محليًا.
- إذن الموقع يُطلب عند اختيار «أنا عند العقار الآن»، وتحفظ الإحداثيات محليًا ويمكن فتحها عبر رابط Google Maps يختاره المستخدم.
- الكاميرا ومكتبة الصور والموقع والصلاحيات ذات الصلة اختيارية، ورفضها لا يمنع تسجيل العقار.
- ملفات PDF والنسخ الاحتياطية والمشاركة تُنشأ محليًا؛ لا تغادر البيانات الجهاز إلا عندما يختار المستخدم الحفظ أو المشاركة عبر خدمة خارجية، وعندها تنطبق سياسة تلك الخدمة.
- حذف التطبيق يحذف بياناته المحلية ما لم توجد نسخة احتياطية أنشأها المستخدم أو نسخة جهاز يديرها نظام التشغيل.
- بريد المطور واسم المطور الفرد مطابقان للموقع المرجعي الذي زوّد به مالك التطبيق.

## الاعتمادية والأمان

- الموقع ثابت بالكامل ويعمل حتى عند تعطيل JavaScript.
- لا توجد طلبات شبكة بعد تحميل مستندات الموقع وملفاته الذاتية.
- الاتصال الخارجي الوحيد من الصفحة هو فتح تطبيق البريد عند اختيار المستخدم؛ أما التنقّل بين الدعم والخصوصية فمحلي داخل الموقع.
- لا تعرض الصفحات أرقام عقارات أو بيانات عملاء أو أي بيانات خاصة من التطبيق.

## التحقق

- التحقق من HTML والروابط المحلية وعدم وجود موارد أو أدوات تتبع خارجية.
- اختبار العرض عند عرض هاتف ضيق وسطح مكتب، واتجاه RTL والنص المكبّر ولوحة المفاتيح.
- فحص أن رابط البريد وعنوان الرسالة صحيحان.
- التحقق بعد النشر من استجابة رابطَي GitHub Pages بنجاح ومن ظهور المحتوى المنشور.
